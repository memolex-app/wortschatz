# Memolex

Vocabulaire allemand-français et italien-français par répétition espacée (langue choisie au premier lancement). Appli web installable (PWA), hors ligne, synchronisée via Supabase.

En ligne : https://frankcarnation-prog.github.io/memolex/

Sources des données et licences : voir le Guide de l’appli (Tatoeba CC BY 2.0 FR, Wiktionary/FreeDict/WikDict CC BY-SA, wordfreq, Lexique 3.83 ; pour l'italien : Tatoeba, wordfreq, spaCy it_core_news_lg).
